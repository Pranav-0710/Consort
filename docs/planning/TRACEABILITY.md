# Traceability: planning requirements → issues

This maps each requirement and proof obligation in the planning baseline to the GitHub issues that address it. **A mapped issue is a plan, not evidence.** A requirement counts as met only when its issue's acceptance criteria are checked against real behavior.

When an issue's scope changes, or a new issue takes over a requirement, update this file in the same PR.
